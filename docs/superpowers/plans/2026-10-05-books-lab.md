# The Books Lab Implementation Plan

**Goal:** Deliver the eight-module static bookkeeping course described in course-builder-prompt.md.

**Architecture:** Content JSON drives independently rendered exercises. A pure scoring engine handles grading and competency; a guarded store handles progress; the UI renders dashboard, module, review, and report routes. No runtime dependencies or build step.

**Tech stack:** HTML, CSS, ES modules, Node built-in test runner, GitHub Pages, optional Apps Script.

- [x] Write engine tests for multi-select exactness, balanced-but-wrong entries, repeated attempts, mastery, storage failure, and capstone dollar effects. Run `node --test tests/engine.test.mjs` and observe missing-engine failure.
- [x] Implement `js/engine.js`, `js/store.js`, and `js/sync.js`; rerun tests.
- [x] Author `content/course.json`: eight modules, short lessons, three practice activities, missions, checks, a 30-line capstone, six exceptions, and reconciliation. Verify every answer key and accounting entry with `node tests/content.mjs`.
- [x] Implement `js/components.js` for choice, sorting, journals, equation, flow, bank feed, reconciliation, missions, and video. Use keyboard-operable alternatives to dragging.
- [x] Implement `index.html`, `styles/app.css`, and `js/app.js`: responsive dashboard, sequential lesson sections, progress, badges, missed-question review, and printable/JSON report.
- [x] Implement `config.js`, `apps-script/Code.gs`, and documentation for optional nonblocking Sheets sync, retry limitations, and setup.
